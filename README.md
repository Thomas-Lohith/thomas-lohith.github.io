# Portfolio site — Thomas Routhu

## What's here
- `index.html` — the page
- `assets/css/styles.css` — all styling
- `assets/js/main.js` — mobile nav toggle
- `resume.pdf` — your CV, linked from the "Download résumé" button
- `assets/img/` — add your photo here (see below)

## Add your photo
Save your photo as `profile.jpg` inside `assets/img/` (a square photo, at least 500×500px, works best — it's cropped into a circle). Until you add it, the hero shows your initials "TR" instead.

## Deploy to GitHub Pages
1. Create a repo named `yourusername.github.io` on GitHub.
2. Upload all the files/folders in this project, keeping the folder structure intact (`assets/` must stay a subfolder).
3. In the repo, go to **Settings > Pages**, set source to the `main` branch, `/ (root)` folder, and save.
4. Your site goes live at `https://yourusername.github.io`.

## Notes
- The contact section uses `mailto:` and `tel:` links — no backend needed, so nothing to configure.
- If you ever want a working contact *form* (not just mailto links), that needs a form-handling service like Formspree, since GitHub Pages only serves static files. Happy to wire that up if you want it.
